WindowsAgentArena

waa · v0.1.2

📖 Getting Started
os gui desktop multimodal

Windows Agent Arena (WAA) benchmarks multimodal agents on real Windows 11 desktop tasks across applications like File Explorer, Edge, Chrome, VLC, and settings. Each task launches a Windows VM, runs setup, and evaluates the final desktop state. Ported to the CUBE protocol.

By: @recursix (Alexandre Lacoste) , @amanjaiswal73892 (Aman Jaiswal) , @kushasareen (Kusha Sareen)
